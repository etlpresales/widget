How to test the live agent

  1. Wait for all four status checks above to turn green.
  2. Click the chat bubble (usually bottom-right corner).
  3. Send a test message, e.g. Test message from GitHub Pages.
  4. Log in to your AnyChat agent dashboard and confirm the conversation appears.
  5. Reply from the dashboard and confirm the reply shows up here in the widget.
  6. Repeat on mobile and in an incognito window to test as a new visitor.
